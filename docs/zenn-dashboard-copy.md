# Zenn応募フォームの保存文面

保存内容を記録しています。
読みやすさのため、改行を調整しています。

## プロジェクト概要

マンガ、書籍、ゲームを複数のショップで買うファンのためのSNSです。
楽天ブックス、Amazon、Steamなどに分散した購入作品を一つの棚にまとめ、好きな作品を通じて趣味の仲間とつながれます。
6つのAIの役割が、購入履歴の取り込み、公開前のプライバシーチェック、自己紹介の下書き、相性分析、AI分身との会話、価格や新作の巡回を支援します。
取り込んだ作品は下書きに保存し、公開範囲とAI自己紹介の反映は本人が確認して決定。
公開棚から気になる作品を見つけ、購入リンクでショップへ進めます。

## 課題と解決

**買ったものが、あなたの自己紹介になる。**

マンガ、書籍、ゲームを複数のショップで買うファンは、購入履歴が分散し、棚を手作業でまとめる負担を抱えています。
健康、金融、贈り物など、人に見せたくない商品も混ざり、そのままの共有には不安があります。

推し棚は購入作品を一つの棚にまとめ、本人が公開する作品と範囲を選ぶSNSです。
ブックマークレットの商品カード、テキスト、スクリーンショット、商品URLから取り込み、必ず下書きに保存します。
ショップのログイン情報は預かりません。
AIのプライバシーガードが要確認商品と公開範囲を提案し、本人が確認して公開します。

公開棚からAIが自己紹介を下書きし、承認後に反映。
相性分析は共通点や話しかけ例を提案し、フォロー相手のAI分身は棚の検索ツールでおすすめを探します。
ウォッチャーは価格と新作を巡回し、通知します。
気になる作品から購入リンクでショップへ進めます。

年齢制限のある作品も下書きで扱い、他の人への表示には18歳以上の申告と表示同意を要求します。
AI利用は所有者の別の同意が必要で、タイトル、画像、URL、メモを伏せ、ジャンルとタグだけを使います。

画像はサンプル画面です。
取り込みはページ構造により取りこぼしがあり、AI出力は本人が確認します。
定期巡回の実行時刻、全ショップでの取り込み、成人向け同意を有効にした複数アカウントの動作は未確認です。

## アーキテクチャ説明

Cloud Run上でNext.jsの画面とServer Actionsを実行し、Firebase Authenticationの認証情報をサーバーのセッションCookieへ交換します。
Firestoreは棚、フォロー、通知、監査記録を保存し、嗜好ベクトルによるユーザー推薦も担います。

Vertex AI経由でGeminiを利用します。
取り込みとプライバシーガードはGoogle Gen AI SDKによる構造化出力のパイプラインです。
プロフィール、相性分析、AI分身、ウォッチャーはADKのツール使用エージェントで、棚の概要、カテゴリ、検索などをモデルが選び、結果をもとに次の行動を決めます。
呼び出したツールを画面に表示します。

Cloud Schedulerがウォッチャーを定期起動し、OIDCトークンの宛先とサービスアカウントを検証します。
手動巡回にも対応し、成功と失敗をFirestoreに監査記録として残します。
値下がりは取得価格をコードで比較し、検索回数と通知件数を制限します。

書き込み時は認証と所有者をサーバーで検証し、Firestoreへのクライアント直接アクセスを拒否します。
下書き、非公開、フォロワー限定の作品は公開向けAI入力から除外。
外部URL取得はSSRF対策を経由し、モデルが返した作品IDと商品カードのURLを照合します。
ユーザーとサービス全体の日次AI利用上限を同一トランザクションで予約します。

既定モデルはGemini 2.5 Flash、分類とガードはFlash-Lite、嗜好ベクトルはgemini-embedding-001です。
図は現行構成を示し、定期実行履歴や安全性修正の本番反映を確認済みとするものではありません。

## 動作確認の方法

対象URL：https://oshi-dana.com
ログイン画面の「デモアカウントでログイン」を押してください。
Googleアカウントの選択やメール受信は不要です。
共有の審査用アカウントで、サンプルユーザー「デモ太郎」「みか」「けんじ」「てつ」「ゆき」の棚を確認できます。
所要時間はAIの待ち時間を含め5〜10分程度が目安です。

1. 「自分の棚」で作品を確認し、「ショップで見る」「ショップで探す」で外部サイトへ進めます。
購入は不要です。

2. 「取り込む」で以下の架空テキストを入力します。
重複時は検証用の識別子を足してください。

検証用架空作品 星の図書館の冒険 2026/10/14
検証用架空作品 小さな町の料理日記 2026/10/14
検証用架空作品 借金返済の家計ノート 2026/10/14
結果は下書きです。
「確認して公開」で要確認商品の選択が外れていることを確認し、公開してよいサンプルだけ選んで公開範囲を設定してください。

3. 「設定」の「自己紹介を生成する」（生成済みなら「もう一度生成する」）で下書きと行動ログを確認し、承認する場合だけ「この内容でプロフィールに公開」を押します。
生成だけでは反映されません。

4. 「見つける」から「みか」の棚を開き、「相性を分析する」で共通点、おすすめ、話しかけ例を確認します。
生成済みなら「再分析」を使えます。

5. 同じ棚の「AI分身と話す」で「初心者におすすめの1冊を教えて」を選び、回答中の作品リンクを確認します。

6. 「ほしい」で商品ページのリンクを持つ作品を確認し、「通知」の「今すぐ巡回する」を押します。
価格、通知件数、行動ログを確認します。
値下がりがなければ値下がり通知は出ません。

7. 終了時はログアウトしてください。

共有アカウントの既存作品やプロフィールは削除せず、実際の購入履歴、個人情報、成人向け作品を入力しないでください。
AI利用枠は利用者全員で共有し、使い切った場合はエラーになります。
日次枠は日本時間午前9時に切り替わります。
主な上限は取り込み解析40回、スクリーンショット15枚、自己紹介10回、相性30回、分身60回、手動巡回5回です。
サービス全体の枠もあります。
これらは現行コード上の制御で、本番反映は今回未確認です。

取り込みにはショップ構造による取りこぼしがあり、同一商品はスキップします。
相性は24時間以内の保存結果を再利用します。
新作情報はAIの提案で、発売日は公式情報で確認が必要です。
価格取得に失敗する商品や検索結果リンクは価格監視に向きません。
