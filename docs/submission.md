## プロジェクト説明文（案）

> **推し棚（OshiShelf）― 買ったものが、あなたの自己紹介になる。**
>
> FANZA・DLsite・Amazon・Steam など、どこで買った作品も「棚」に並べて公開し、同じ趣味のファン同士がつながれる SNS です。フォローした人の棚から、気になる作品の商品ページへそのまま飛んで購入できます。
>
> 購入履歴は趣味をいちばん正直に表すのに、ショップごとに閉じていて見せ合えません。手で棚を作るのは面倒で、しかも健康・お金・贈り物・成人向けなど「見られたくない物」が混ざります。推し棚では 6 つの AI エージェントがこの課題を解決します。
>
> 1. **取り込み**: 購入履歴ページ上のブックマークレット・スクショ・URL から商品を一括抽出（ログイン情報は預からない）
> 2. **プライバシーガード**: 公開前に「見られたくないかも」を検出して公開範囲を提案。公開は必ず本人が決める
> 3. **プロフィール**: ADK エージェントが棚をツールで探索して嗜好を推論し、自己紹介を下書き（承認制）
> 4. **相性マッチング**: 嗜好ベクトル（Firestore ベクトル検索）で近い人を推薦し、相性・おすすめ・話しかけ例を提案
> 5. **AI 分身チャット**: 相手の公開棚だけを知る分身に、おすすめを聞ける
> 6. **ウォッチャー**: Cloud Scheduler で毎朝自律巡回し、ほしい物の値下がりと新作を通知
>
> 「判断は AI、事実の検証はコード」を徹底し、値下がり判定のコード検証、ツール呼び出しの上限、作品 ID の実在チェック、監査ログ、成人向け作品の AI 非送信、SSRF 対策、ユーザー別の AI 利用上限などで、安心して任せられるエージェントを目指しました。
>
> 技術: Cloud Run（Next.js 16）/ Agent Development Kit / Vertex AI Gemini 2.5 Flash・Flash-Lite / gemini-embedding-001 / Firestore ベクトル検索 / Firebase Authentication / Cloud Scheduler
