# 推し棚 デモ動画 台本（約3分）

- 公開先: YouTube（公開）
- 画面: PC ブラウザ 1280×800 前後、拡大率 125% 程度で文字を大きく
- 使うアカウント: デモアカウント（ログイン画面の「デモアカウントでログイン」）
- AI の応答には 20〜40 秒かかるので、**待ち時間は編集でカット**し、「（早送り）」の字幕を入れる

## 撮影前の準備

- [ ] 本番 URL を開き、デモアカウントでログインできることを確認
- [ ] 取り込み用のテキストを用意（下の「貼り付け用テキスト」）。前回の下書きが残っていたら「確認して公開」画面で削除しておく
  - 同じ商品は二重に取り込まれない仕様なので、撮り直すときは「棚の編集」で公開済みの同じ商品も削除しておく
- [ ] FANZA・Amazon などの購入履歴ページは、**実際の購入履歴や氏名・住所が映らないよう** に、撮影用のテスト画面かぼかしで対応する
- [ ] 通知の「🔔」に赤い数字が出ていない状態にしておく（通知画面を一度開く）
- [ ] 相性分析は一度実行しておくとキャッシュで即表示される。動画では「再分析」を押して早送りでもよい
- [ ] ブラウザの拡張機能アイコンやブックマークバーの私物を隠す

## 台本

| 時間 | 画面 | ナレーション |
|---|---|---|
| 0:00–0:15 | トップページ（ログアウト状態）。キャッチコピーと6つのエージェントのカードを映す | 「何を買ったか」は、その人の趣味をいちばん正直に表します。でも購入履歴はショップごとに閉じていて、ファン同士で見せ合えません。推し棚は、どこで買った作品でも棚に並べて公開し、同じ趣味の人とつながれるSNSです。 |
| 0:15–0:25 | ログイン画面 →「デモアカウントでログイン」→ フィード | フォローした人の棚が並ぶフィードです。気になった作品は、ワンクリックでショップの商品ページに飛べます。 |
| 0:25–0:55 | 「取り込む」→ 方法A（ブックマークレット）の説明を一瞬映す → 方法B に貼り付け用テキストを貼って「解析して取り込む」（早送り） | 購入履歴の取り込みはエージェントの仕事です。ショップの購入履歴ページでブックマークレットを押すだけで、ページ上の商品リンクを一括で読み取ります。ログイン情報は推し棚に一切渡りません。今回はページのテキストを貼り付けてみます。 |
| 0:55–1:20 | 「確認して公開」画面。要確認3件（妊娠検査薬・借金の本・ギフト）がチェックの外れた状態で並ぶ。理由の文言にズーム。安全な3件だけ「公開」 | 取り込んだ商品は、すぐには公開されません。プライバシーガードが「見られたくないかも」という商品を先に見つけて、チェックを外した状態で見せてくれます。注文番号やお届け先は、そもそも取り込まれていません。公開するかどうかは、必ず本人が決めます。 |
| 1:20–1:45 | 「設定」→「自己紹介を生成する」（早送り）→ 下書きと「エージェントの行動ログ」を開く →「この内容でプロフィールに公開」 | 棚がそろったら、AIに自己紹介を書いてもらいます。エージェントは、棚の傾向を調べるツールや検索ツールを自分で使い分けてから書きます。どのツールを使ったかは行動ログで確認でき、文章は本人が承認してから公開されます。 |
| 1:45–2:15 | 「見つける」→ 嗜好の近さ％の一覧 → みかさんのページ →「相性を分析する」（早送り）→ スコア・おすすめ・話しかけ例 | 棚の作品をベクトル化し、趣味が近い人を推薦します。プロフィールを開くと、相性分析エージェントが2人の棚を比べて、相性の理由と、相手の棚からあなたへのおすすめ、最初の話しかけ方まで提案してくれます。 |
| 2:15–2:35 | 同じページの「AI分身と話す」→「初心者におすすめの1冊を教えて」→ 回答のリンクをクリックしてショップが開く | こちらは、相手の公開棚だけを知っているAI分身です。おすすめを聞くと、棚の中から答えてくれて、そのまま購入ページに飛べます。 |
| 2:35–2:55 | 作品の ♡ を押す →「通知」→「今すぐ巡回する」（早送り）→ 行動ログと通知 | ほしい作品に♡を付けると、ウォッチャーエージェントが毎朝自動で巡回し、値下がりや好きなジャンルの新作を知らせてくれます。値下がりの判定はAI任せにせず、コードで価格を検証してから通知します。 |
| 2:55–3:10 | アーキテクチャ図（docs/architecture.png）→ 最後にトップページとURL | 推し棚は Cloud Run 上の Next.js と、Agent Development Kit、Vertex AI の Gemini、Firestore のベクトル検索で動いています。買ったものが、あなたの自己紹介になる。推し棚でした。 |

## 字幕・テロップ案

- 0:25「📥 取り込みエージェント」
- 0:55「🛡️ プライバシーガード ― 公開は本人が決める」
- 1:20「✍️ プロフィールエージェント（ADK）」
- 1:45「🤝 相性マッチング（Firestore ベクトル検索 + ADK）」
- 2:15「💬 AI分身チャット」
- 2:35「👀 ウォッチャー（Cloud Scheduler で毎朝自律巡回）」
- AI の待ち時間：「（早送り）」

## 撮影のコツ

- macOS なら「⌘ + Shift + 5」で画面収録できます
- ナレーションは後から録音して重ねると、言い間違いを直しやすいです
- 3分を超えそうなら、1:20–1:45（自己紹介）の説明を短くするのがおすすめです
