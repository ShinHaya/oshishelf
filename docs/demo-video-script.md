# 推し棚 デモ動画の確定台本（3分）

2026年10月13日の現行UIと撮影結果をもとに、180秒の構成に確定しました。
実際の画面を静止画として撮影し、場面の切り替え、日本語の合成ナレーション、焼き込み字幕を付けた動画です。
連続した画面録画ではありません。
AIの待ち時間を省略したことを全場面で表示します。

## 撮影条件

- 対象は https://oshi-dana.com の共有デモアカウント。
- フィードはサンプルユーザーの作品だけを採用し、ログアウト時の実購入作品一覧と推薦欄の実ユーザーは映さない。
- 新しい架空履歴3件を取り込み、一般向けの2件だけを確認して公開する。
- 既存の下書きに含まれる名前と、取り込み方法や設定の不要な説明は、撮影画像の切り抜きで除く。
- 相性分析は保存済みの結果を表示し、字幕とナレーションでその旨を伝える。
- 新作通知はAIの提案として紹介し、発売日の正確性を確認済みと扱わない。
- ブラウザのページ内だけを撮影し、タブ、アドレスバー、ブックマーク、拡張機能は含めない。

## 180秒の構成

| 時間 | 実画面と編集 | ナレーション |
| --- | --- | --- |
| 0:00–0:15 | 課題と利用者像のタイトルカード | 推し棚は、マンガやゲームを買う人のためのSNSです。購入履歴はショップごとに分かれ、趣味の仲間に見せるには手作業が必要です。好きな作品をまとめて、同じ趣味の人とつながる。その手間を、エージェントが支援します。 |
| 0:15–0:25 | 共有デモのフォロー中フィード | これはデモアカウントのフィードです。フォローした人のマンガやゲームが並びます。作品の購入リンクからショップへ進めるので、趣味のつながりが、新しい作品との出会いになります。 |
| 0:25–0:43 | ブックマークレットの説明と架空履歴の入力欄 | 取り込みには、ブックマークレット、スクリーンショット、商品URLを使えます。購入履歴ページは本人のブラウザで読み取り、ログイン情報を預かりません。今回は架空の履歴を貼り付けました。取り込みエージェントが作品を抽出し、プライバシーガードが確認の必要な商品を判定します。 |
| 0:43–1:03 | 未選択の要確認商品、選択済み2件、公開ボタンの切り抜き | 取り込んだ3件は、すべて下書きになりました。借金に関するサンプルは要確認となり、選択が外れています。AIの提案を見て、本人が公開範囲と作品を決めます。ここでは一般向けの2件だけを選択しました。下書きを生成しただけでは、公開されません。 |
| 1:03–1:15 | 本人確認後の棚に並ぶ2件 | 公開ボタンを押すと、選んだ2件が棚に並びました。要確認のサンプルは下書きのままです。公開前の確認を挟むことで、見せたい作品だけを、趣味の自己紹介として共有できます。 |
| 1:15–1:38 | 自己紹介の下書き、編集欄、3ステップの行動ログ、承認ボタン、承認後のプロフィール | プロフィールエージェントは、全体公開の棚を調べて自己紹介を書きます。今回の行動ログには、棚の全体傾向、ゲーム、マンガを確認した3ステップが残りました。エージェントが選んだツールと、その行動を画面で追えます。文章は編集でき、この内容でプロフィールに公開、を押して初めて反映されます。 |
| 1:38–2:00 | みかとの相性75、共通点、おすすめ、話しかけ例、2ステップのログ | 棚の作品やタグをベクトル化し、Firestoreのベクトル検索で趣味が近い人を推薦します。こちらはサンプルユーザー、みかさんとの相性分析です。2人の棚を比較し、相手の棚を検索した結果から、共通点、おすすめ、話しかけ例を表示します。今回は保存済みの分析を表示しています。スコアは会話のきっかけとなる提案です。 |
| 2:00–2:20 | 質問、作品リンク付き回答、1ステップの行動ログ | AI分身には、初心者におすすめの本を質問しました。本人の代わりに、公開棚をもとにおすすめを答えます。今回はハクメイとミコチ、とんがり帽子のアトリエを紹介しました。作品名にはショップへ進むリンクが付きます。分身は本人ではないことも、画面に明示しています。 |
| 2:20–2:40 | 価格確認2件、値下がり0件、新作2件、8ステップのログ | ウォッチャーは、ほしい作品の価格と、好きなジャンルの新作を毎朝調べます。手動巡回では、価格確認2件、値下がり0件、新作通知2件でした。価格はコードで検証し、検索や通知の行動も記録します。新作情報はAIの提案なので、発売日などは公式情報で確認が必要です。 |
| 2:40–3:00 | 既存のGoogle Cloud構成図 | アプリはCloud Run上のNext.js、エージェントはADKとVertex AIのGeminiで動きます。Firestoreが棚とベクトル検索を支え、Firebase Authenticationで認証し、Cloud Schedulerが巡回を起動します。買ったものが、あなたの自己紹介になる。推し棚です。 |
