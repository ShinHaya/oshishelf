# デモ動画の撮影と公開の記録

## 制作条件

2026年10月13日に、Issue #25の指示に基づき本番の共有デモアカウントで架空データを使って撮影しました。
アプリのコード、本番のデプロイ、seed、Firestoreの設定は変更していません。

実画面の静止画を切り替え、字幕と日本語の合成ナレーションを付けた3分の動画です。
連続した画面録画ではありません。
切り抜きは実画面の該当部分を並べたもので、AI回答や選択状態を書き換えていません。
AIの待ち時間をカットしたことを全場面に表示します。
確定した時間割と全文は [台本](demo-video-script.md) を参照してください。

## 映像から除いた情報

ログアウト時のトップページにある実購入作品と、推薦欄の実ユーザーを除きました。
既存の下書きにある名前、取り込みや設定の不要な説明も切り抜きで除いています。
成人向けサイト名や直接的な紹介、実購入履歴、氏名や住所、認証情報、私物のブックマークは動画に含めません。
ブラウザのタブやツールバーを含めず、ページ内だけを撮影しました。

## 制限と未確認の範囲

前提のIssue #24は完了していますが、Issue #27は撮影時点で未完了です。
この動画の公開を、安全性や費用に関する既存Issueの解決の証跡として扱わないでください。

分身の最初の回答では、作品IDの代わりに作品名を使ったリンク記法がそのまま表示されました。

リンク表示の失敗と説明の矛盾は、この資料変更では修正していません。

ウォッチャーの新作名と発売日は検証していません。
動画でも公式情報での確認が必要と説明しています。
値下がり通知が実際に発生する場面、各ショップの実購入履歴、スクリーンショット取り込みは今回撮影していません。
相性分析はキャッシュを使い、全機能を今回新規生成したとは説明していません。

長さは180.095秒、容量は4,959,243バイトです。
字幕は映像へ焼き込み、同じ内容の [SRT](demo-video.srt) も保存しました。

全編の人による聴取は未実施です。
