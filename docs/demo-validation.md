# 審査用デモの操作手順と確認記録

## 動作確認の方法

対象URLは https://oshi-dana.com です。
ログイン画面で「デモアカウントでログイン」を押してください。
共有の審査用アカウントへログインするため、Googleアカウントの選択やメールの受信は不要です。
認証情報をフォームに記載する場合は、提出資料にある審査用情報を「審査向け情報」にのみ転記してください。

サンプルユーザー「デモ太郎」「みか」「けんじ」「てつ」「ゆき」の棚で操作できます。
実際の購入履歴、個人情報、成人向け作品は共有アカウントへ入力しないでください。
既存の作品やプロフィールを削除せず、確認してから操作してください。

| 操作 | 手順と期待する結果 |
| --- | --- |
| 棚と購入リンク | 「自分の棚」でマンガ、書籍、ゲームを表示します。「ショップで見る」「ショップで探す」から外部サイトへ移動できます。購入自体は不要です。 |
| 取り込みと本人確認 | 「取り込む」で、架空の購入履歴テキストまたは一般向け商品URLを入力します。結果は下書きになります。「確認して公開」で要確認商品の選択が外れていることを確認し、公開してよいサンプルだけ選びます。 |
| AI自己紹介 | 「設定」の「自己紹介を生成する」（生成済みなら「もう一度生成する」）を押します。下書きと行動ログを確認してから「この内容でプロフィールに公開」を押します。生成しただけでは公開されません。 |
| 相性分析 | 「見つける」からサンプルユーザー「みか」の棚を開きます。「相性を分析する」で共通点、おすすめ、話しかけ例を表示します。生成済みなら「再分析」で新しい分析を実行できます。 |
| AI分身 | 「みか」の棚の「AI分身と話す」で「初心者におすすめの1冊を教えて」を選びます。回答中の作品リンクから商品ページへ移動できます。 |
| ウォッチャー | 「ほしい」で商品ページのリンクを持つ作品を確認し、「通知」の「今すぐ巡回する」を押します。確認した価格、通知件数、行動ログが表示されます。値下がりがなければ値下がり通知は出ません。 |
| 終了 | 「ログアウト」を押します。棚の編集や設定を開くとログイン画面へ戻ります。 |

全体の所要時間はAIの待ち時間を含め5〜10分程度を目安にしてください。
これは操作手順の目安で、応答時間の保証ではありません。
動画は待ち時間をカットして約3分に編集できます。

## 利用上限と繰り返し操作

共有アカウントのAI利用回数は利用者全員で共有します。
現在のコードでは日付をUTCで区切るため、日本時間の午前9時に次の日の枠へ切り替わります。

| 機能 | 1日あたりの上限 |
| --- | ---: |
| テキスト、URL、ブックマークレットによる取り込み | 合計40回 |
| スクリーンショット | 15枚分 |
| AI自己紹介 | 10回 |
| 相性分析 | 30回 |
| AI分身チャット | 60回 |
| 手動ウォッチャー | 5回 |

同じ商品は重複を検出してスキップします。
撮り直しで既存サンプルを削除する代わりに、別の架空サンプルを用意してください。
相性分析は生成から24時間以内のキャッシュを再利用し、「再分析」で再生成します。
プロフィールページの初期表示キャッシュには既存Issue #12の制限があるため、公開範囲を変えた後の表示には注意が必要です。
価格が商品ページから取得できない作品や検索結果リンクは、価格監視の実演に向きません。
